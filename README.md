# Safary Deal Flow Engine — Landing Page

Landing page for Safary Marketing's Deal Flow Engine (borrower-acquisition systems for private & hard-money lenders).

## About

- **`index.html`** — the complete, self-contained landing page. All CSS is inline and the background artwork is an embedded SVG, so the single file can be hosted anywhere with no external assets.
- Branding matches [safarymarketing.io](https://www.safarymarketing.io): Inter typeface, brand blue `#0D81D3`, navy `#0F1729`, and the pale-blue bubble motif.

## Preview locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Hosting

Because it's a single static file, it can be deployed to GitHub Pages, Netlify, Vercel, or any static host. To go live on GitHub Pages, enable Pages on the `main` branch in the repo settings.
